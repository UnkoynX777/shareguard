# Support

| Topic | Where |
| --- | --- |
| Something is broken | [Bug report](https://github.com/UnkoynX777/shareguard/issues/new?template=bug-report.yml) |
| A change you want | [Feature request](https://github.com/UnkoynX777/shareguard/issues/new?template=feature-request.yml) |
| Install and connection problems | [Troubleshooting](./docs/TROUBLESHOOTING.md) |
| A security vulnerability | [SECURITY.md](./SECURITY.md) |

Please do not open a public issue for a vulnerability.

Questions about how the current version behaves can use a bug report when something fails, or a feature request when the product is working as designed and you want a change. ShareGuard does not run a separate support desk.

# Suporte

| Assunto | Onde |
| --- | --- |
| Algo está quebrado | [Relato de bug](https://github.com/UnkoynX777/shareguard/issues/new?template=bug-report.yml) |
| Uma mudança que você quer | [Pedido de recurso](https://github.com/UnkoynX777/shareguard/issues/new?template=feature-request.yml) |
| Problemas de instalação e de conexão | [Solução de problemas](./docs/TROUBLESHOOTING.pt-BR.md) |
| Uma vulnerabilidade de segurança | [Segurança](./SECURITY.pt-BR.md) |

Não abra uma issue pública para uma vulnerabilidade.

Os formulários estão em inglês. Dá para escrevê-los em português.

Dúvidas sobre o comportamento da versão atual podem usar um relato de bug quando algo falha, ou um pedido de recurso quando o produto funciona como foi desenhado e você quer uma mudança. O ShareGuard não tem um canal de suporte separado.
